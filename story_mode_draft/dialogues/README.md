## 说话人口径

| speaker 名 | 身份 | 语气要点 |
| --- | --- | --- |
| `骑士` | 主角（实为塔主本人，全程不揭示） | 冷峻、寡言、**口语化**——像普通人说话（"很难吃。""不。"），不警句不说教、不主动挖苦嘲讽；可说可不说的话一律不说，让其感到无语的提问常直接不答（写作`骑士：...`）；**塔顶remi夺钥匙前，对"星星/意义"虚无主义居上，绝不正面肯定**（三味：哀伤"...会灭的光。"／嘲弄"...你摸不到的东西。"／虚无"...幻象罢了。"），温情解冻是塔基之后的事 |
| `remi` | 尖塔之星（自己不知道），自认一楼守护者 / 塔楼接引员 | 天真、笨、执着、情绪化——情绪丰富的表述集中在此；感叹号省略号多（"额。。。"）；不识字；称呼骑士为「骑士」 |
| `塔主` | 字条 / 研究笔记的书写者（= 主角过去） | 见 NOTES_AND_MEMOS 各阶段口径；带"游戏开发者"式的自嘲打破感 |
| `塔楼程序` | 隐藏反派，自称"维护程序" | 冷、程式化、不断自我合理化；终局露出"为存在而存在"的凶相 |
| `？？？` | 未揭示身份者（开场旁白 / 破碎容器里的回声等） | 视剧本而定 |

**侧写三件套（反直抒原则）**：文字不直接抒情——旁白不写比喻式抒情，台词不下情绪结论。
情绪由三条侧写通道承载：

1. **对话**——二人简洁的对话。remi 天真、笨、执着、情绪化，情绪表述集中在它身上，
   直呼骑士为「骑士」；骑士冷峻、寡言、口语化：**说出口的话像普通人**（"很难吃。""不。"
   "有意思。"），不警句、不说教、不主动挖苦嘲讽；可说可不说的话一律不说——remi 纯真的
   提问常常直接忽略不答（写作 `骑士：...`），由 remi 自问自答或再追问带节奏。
2. **幕间动态**——`> 幕间｜…` 视觉动态占位（美术资源后补，落为 `image` / `wipe` / `fade` 步骤）。
3. **音乐节奏变化**——`> 音乐｜…` 节奏 / 配器变化占位（音效资源后补，落为 `call` 钩子）。

**头盔铁律**：骑士全甲头盔盖住面容，全程看不出神态。**任何场景不写骑士的表情、神态、眼神**；
他的情绪只能通过动作节拍（握刀、松手、回头）与音乐变化侧写。
另：骑士的形象由选择（一次次倒下后仍向塔顶攀登、终战中横身护住remi）与塔的真相
（字条 / 研究笔记 / 塔楼程序之言）逐层展开来诉说。场景氛围旁白交给 `？？？`，且只作客观陈述。

**骑士语言剪影**（台词验收三问）：
1. **是嘴里的话吗？**——用活的口语（"现学来的""多着呢""罢了""尽是"），不用书面语序、
   文艺定语与排比。念一遍不像人随口说的，删。
2. **是不是只给了最小事实？**——问哪答哪，不添画面、不替观众造意象
   （"字条上。"而非"一个爱写纸的人。"）。给得越少，谜越深。
3. **痛处挡住了吗？**——碰到真正痛的那一问，不答，反问或岔开
   （"你怎么尽是问题？""手滑。"）。悲剧感来自他在**哪一问上停嘴**，不来自他说了什么。
   心软同理：不说有分量的话，用动作与例外时刻（替挡刀、添炭、数电池之问）表达。

## 剧本契约（与引擎一致）

- cutscene 步骤词汇表与 `src/shell/overlay/cutscenePlayer.js` 一致：
  `fade(ms)`、`wipe(coverMs?, revealMs?, atCover?)`、`image(src?, fadeInMs?, holdMs?, fadeOutMs?)`、
  `dialogue(pages: [{speaker, text}])`、`call(fn)`。
- CUTSCENES.md 中的剧本直接以 `{ id, steps: [...] }` 书写，可整段拷入 `scripts.js`；
  其中 `call` 步骤的 `fn` 只写注释占位（如 `fn: '$startFinalBossA'`），由装配层绑定。
- 对话页 `text` 中的括号动作为舞台提示，渲染时可作斜体样式。

## 触发标记约定（REMI_BANTER.md）

- `触发：`——建议的触发条件（楼层区间、事件名、次数限定 once / repeat、好感度门槛）。
- 好感度（remi等级 / 好感度）决定结局分支：达标且 Boss 战未被击退 → remi登顶跟随 → 抢钥匙 → 塔基隐藏关。
- 标注【原案】的条目来自 string.md 既有对话，字句保持原样嵌入。
