# 塔主的字条与研究笔记

按**建议挂载楼层**排序。每条含：正文（~~删除线~~ 表示塔主自己划掉的字）、写作时期（对应塔主心路四阶段）、可选的**伴随对话**（拾取笔记时可触发的主角×remi短对话——remi不识字，主角念或不念，皆是自嘲的机会）。

塔主心路四阶段（笔记的隐藏时间轴，供笔迹 / 纸张旧新程度做视觉区分）：

1. **造塔之初**——字迹工整，语气宏大 ("星星会拯救一切")
2. **动力满满**——字迹密集，写满批注，偶尔兴奋 ("今天又排除了一千种不可能！")
3. **灰心丧气**——字迹潦草，大量划掉 ("算了"出现频率升高)
4. **游戏化改造 / 离开**——笔触放松，自嘲，开发者口吻 ("原谅我罢")

> 挂载楼层是玩家读到的顺序，不是写作顺序——塔主离开前把毕生的纸都钉在了塔里。

## 8 层 · 研究笔记 【新增】（时期二）
